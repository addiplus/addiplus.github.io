# addiplus.github.io

Source for Joe Smith's portfolio at https://addiplus.github.io

Hand-built static HTML. No Jekyll, no theme, no build step, no external assets, no analytics.
`.nojekyll` is present so GitHub Pages serves the files as they are.

- `index.html` : the single-page portfolio. Inline CSS and a small inline script for the light/dark switch and the copy-email button.
- `LICENSE` : MIT.
