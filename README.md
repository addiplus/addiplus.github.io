# addiplus.github.io

Source for the evidence index at https://addiplus.github.io

Hand-built static HTML. No Jekyll, no theme, no build step, no external assets, no analytics.
`.nojekyll` is present so GitHub Pages serves the files as they are.

- `index.html` : the single-page index. Inline CSS, no scripts.
- `posts/` : standalone post pages, same conventions.
- `LICENSE` : MIT.
